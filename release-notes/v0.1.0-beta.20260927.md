## Highlights

- Added a Portainer stack for a system Nginx on the same Linux host. The
  container uses host networking but binds the sync server only to
  `127.0.0.1:47732`.
- A new installation can create its first administrator from Portainer stack
  variables, without a separate bootstrap container. The password is hashed
  in the data volume, and subsequent starts never reset it.
- The container image published as `latest` follows the newest GitHub Release,
  not the development branch. The existing container-proxy stack remains
  available.

## Главное

- Добавлен стек Portainer для системного Nginx на том же Linux-хосте. Контейнер
  использует сеть хоста, но сервер слушает только `127.0.0.1:47732`.
- Администратор при новой установке создаётся из переменных стека, без
  отдельного контейнера. В томе хранится хеш пароля, а перезапуск его не
  сбрасывает.
- Тег образа `latest` соответствует последнему GitHub Release, а не ветке
  разработки. Прежний стек для контейнерного прокси сохранён.
